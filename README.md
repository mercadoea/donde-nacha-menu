# Nacha Fast Food — Menú QR v2

Menú digital para GitHub Pages.

### Personalización
- Asados: opción **Sin ensalada**.
- Perros calientes: **Sin lechuga** y **Sin piña**.
- Salchipapas: **Sin lechuga**, **Sin piña** y, cuando el plato incluye maíz, **Sin maíz**.
- Las modificaciones no tienen costo adicional y pueden editarse desde el carrito.

### Confirmación
Se solicitan:
- Nombre.
- Número de contacto.
- Domicilio o recoger en tienda.
- Dirección solo cuando es domicilio.
- Pago: efectivo o transferencia.
- Observaciones.

Los pedidos se generan para WhatsApp `323 712 7014`.

### Publicación
Subir `index.html`, `styles.css`, `app.js` y `logo.png` al repositorio `mercadoea/donde-nacha-menu`, rama `main`, y dejar GitHub Pages apuntando a `/root`.
